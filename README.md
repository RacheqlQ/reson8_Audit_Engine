# Reson8 Audit Engine

Reson8 Audit Engine generates evidence-labelled A&R and music-catalogue audit reports from uploaded audio masters or supported DSP metadata.

Payments are currently disabled. Before any public paid launch, set PAYMENTS_ENABLED=true and complete the Flutterwave and owner-access work.

Environment variable names: NODE_ENV, PORT, AUDD_API, SUPABASE_URL, SUPABASE_SECRET_KEY, GROQ_API, GROQ_MODEL, PUBLIC_AUDIT_OWNER_EMAIL, PUBLIC_AUDIT_RATE_LIMIT_PER_HOUR, PAYMENTS_ENABLED.
